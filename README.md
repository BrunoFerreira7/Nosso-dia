# Happy 23rd Birthday Lemon Anu! 🎂

A beautiful, animated birthday celebration website built with **Next.js**, **Framer Motion**, and **Tailwind CSS**. Dedicated to Lemon Anu on her 23rd birthday.

## Features

- Animated hero section with a gradient name display
- Interactive folding-card timeline celebrating 23 years
- Floating words orbit animation with birthday wishes
- A personalised birthday letter with animated effects
- Floating confetti & stars background
- Smooth scroll & parallax effects
- Fully responsive (mobile-first)

## Tech Stack

| Technology | Purpose |
|---|---|
| Next.js | React framework & routing |
| Framer Motion | Animations |
| Tailwind CSS | Styling |
| Lenis | Smooth scrolling |
